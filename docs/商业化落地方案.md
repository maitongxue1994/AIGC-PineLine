# PineLine 商业化落地方案

> 面向：个人开发者（无公司主体）、总预算 ≤5000 元、每周 <10h、擅长剪辑、有微信视频号+小红书。
> 目标：最快拿到第一笔真实收入，ROI 结构性打正、零垫资。
> 本文是策略与执行手册；技术改造进度见 `docs/运维手册.md`（待补）与代码提交历史。

## 一、核心判断：为什么不能一上来就做国内 to C 自助卖积分

国内 to C 自助卖积分，会**同时撞两堵墙**：

1. **收款墙**：个人主体没有合规的「网站内自动收款」通道。微信/支付宝商户号需营业执照；个人收款码禁止远程经营性收款（央行规定，大额会被风控）。
2. **合规墙**：《生成式人工智能服务管理暂行办法》——向境内公众开放自助生成 = 需算法备案，个人无法完成；不合规的境外域名可被「技术措施处置」（有 ChatGPT 类 App 集中下架先例）。

而且——LibTV（哩布哩布，B 轮融资）把国内积分价打到 0.18 元/秒，**个人打不过这种融资补贴的价格战**。

## 二、双轨模式（本方案的骨架）

按访客 IP 地域分流（Cloudflare 免费能判 `request.cf.country`）：

| | 海外流量（非 CN） | 国内流量（CN） |
|---|---|---|
| 形态 | 网站直接付费自助（Paddle）→ 自动发访问码/积分 → 立即用 | 页面不放自助生成购买；展示企业定制服务 + 联系充值 |
| 收款 | Paddle（个人可开、5%+$0.50、代扣税、约 1 天过审） | 闲鱼/淘宝托管 or 个人经营码；企业单走灵活用工平台/税局代开发票 |
| 合规 | 海外无算法备案义务 | 服务式交付（内容乙方，非 AI 服务提供者）+ 私域接单，规避备案墙 |
| 毛利来源 | 积分汇率差（TapNow 同款：Seedance 5s 收 $3、成本约 $1） | 剪辑审美溢价（你的核心优势） |

**关键设计：访问码 = 账户 = 付费凭证。** 预充值制、先付后用、服务端扣积分——**模型成本永远由已收款覆盖，零垫资，ROI 结构性打正**。免费额度只给一次性小额（不够生成视频），杜绝被白嫖烧钱。

## 三、定价（占位，上线前用真实成本核算替换 `src/siteConfig.ts` PRICING）

积分口径：1 积分 ≈ ¥0.1 成本对齐，毛利含在售价里。

**积分包（一次性，永不过期）**
| 套餐 | 积分 | 定价 | 约当 |
|---|---|---|---|
| 体验包 | 1,000 | ¥29 / $5 | ~10 条短视频 |
| 创作包（推荐） | 6,000 | ¥149 / $22 | ~60 条 |
| 专业包 | 20,000 | ¥449 / $68 | ~200 条 |

**月订阅**：轻享 ¥79/月（3,000 积分）、进阶 ¥279/月（12,000 积分 + 优先队列 + 批量导出）。

**成本锚点**（每积分 ≈¥0.1）：Seedance 720p·5s ≈ 100 积分（成本约 ¥5，售价档内毛利 50%+）；Seedance Mini ≈ 60；Seedream/Gemini 图 ≈ 5；文本 ≈ 2。**注意：4k/1080p 成本翻数倍，非管理员默认封顶 1080p（已在 videoCreate 硬校验）。**

**企业定制服务**：面议，按月产能包（如 20 条/月），含 AI 标识 + 存证报告。行情参考：AI 短片代做 300-800 元/条起、企业产品片 800-1500、传统宣传片 5-30 万（AI 把这个市场打到了数百元级，客单 300-1500 是个人可吃的空档）。

## 四、90 天执行路线

### 第 1-2 周：第一笔收入（服务式，最快见钱）
- 用 PineLine 做 3 条不同风格样片（科普/产品/短剧感），发小红书 + 视频号。
- 闲鱼挂「AI 企业短视频代做 399 元起」。**先收款、后生成**（单条成本 60-170 元，先款后做不垫资）。
- 这是所有路径中唯一能两周内见真钱的。

### 第 2-4 周：接海外自助
- 买域名（~¥70/年）绑 Cloudflare、上线 /terms /privacy、开 Paddle → Pricing 海外自助购买闭环打通。
- X（Twitter）每周 2 条 demo GIF/成片对比（语言门槛最低，视频 demo 最有效）；Reddit r/aivideo、r/SideProject 养号后发过程帖。

### 第 1-3 个月：跑量 + 正规化
- 服务单跑到 10-20 单，报价从 399 提到 800-1500（企业产品片档）。
- 单月流水稳过 5,000 元或接到要发票的企业单时 → 花 1,200-1,500 元注册**个体工商户**（7-10 工作日，解决开票 + 国内正规收款）。
- 生成侧成本优化：LibTV 大师版年卡（1,299 元）或 Seedance Mini API 压成本。

### 第 3-6 个月：视验证决定是否 SaaS 化
- 服务过程会告诉你客户真正缺什么。若做 SaaS：**BYOK（用户自带模型 key）+ 收工具订阅费**，绝不做自贴模型成本的积分制（36 氪已证实这条路连融资公司都不赚钱）。
- 小红书接单账号届时就是 SaaS 的种子用户池。

## 五、获客红线（违反 = 封号/违法，必须避开）

| 红线 | 后果 |
|---|---|
| 小红书/视频号笔记、评论、简介留微信（含变体/二维码） | 限流→永久封号。合规路径：群聊 + 私信通留资卡 → 企微/个微名片 |
| AI 内容发布不勾平台「AI 生成」声明 | 限流；违反标识办法 |
| 提供/使用「去 AI 标识」功能 | **明确违法** |
| 网站向境内公众开放自助 AI 生成 | 落入暂行办法，个人无法备案，域名可被处置 |
| 用火山方舟「体验中心」产物商用交付 | 违反平台条款，无商用授权。只走付费 API |
| 生成内容模仿具体 IP 到实质性相似后商用 | 著作权侵权 |
| 未授权真人形象生成数字人 | 违反 Seedance 规则 + 肖像权 |

## 六、to B 机构客户（如《知识就是力量》杂志社）打法

- 机构正式采购走招标（要求案例+合同，个人身份进不去）；**现实路径是小额私下合作**（新媒体编辑部门内可决策，几千元/条量级无需招标）→ 积累案例 → 后期个体户/挂靠投标。
- 动作：用对方公开文章做 2-3 条样片（**仅作提案演示、不公开发布**，避免侵权）→ 通过官网/公众号后台联系新媒体编辑，话术「已按贵刊风格做了样片，免费送审」→ 同模板复制到 10 家科普期刊/学会/医院宣传科。
- 报价按月度服务包（低于传统制作、高于纯模板号质量线）。

## 七、成本与预算（5000 元怎么花）

| 项 | 成本 |
|---|---|
| 域名 | ~¥70/年 |
| Cloudflare（Workers/R2/DO） | 免费档基本够；Workers Paid $5/月可选（解锁 5 分钟 CPU + 完整 DO） |
| 生成成本 | 预充值覆盖，零垫资；自制样片 60-170 元/条 |
| 监控告警 | BetterStack/UptimeRobot 免费档 |
| **合计固定支出** | **年 <500 元**，其余 4500 元是模型试产/样片弹药 |

R2 出站流量永久免费（发视频给客户不花流量钱）；5000 元预算按 Seedance Mini 可试产 50-75 条 60 秒成片。

## 八、运维要点（详见 docs/运维手册.md）

- **国内可达**：workers.dev 在大陆被墙，必须绑自有域名（走 Cloudflare 海外解析，免备案，大陆大概率可达但速度一般）；国内 to B 交付不依赖客户访问网站（微信/网盘交付成片）。
- **告警**：BetterStack 探 /api/health；Cloudflare 用量通知；方舟/MiniMax 控制台余额预警（阈值 30%）。
- **访问码 SOP**：CF Dashboard 改 `PINELINE_ACCESS_CODES` secret 即时发放/作废；`admin-` 前缀码自用（免限流免扣费）。
