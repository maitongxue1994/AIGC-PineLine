# Studio 画布架构 v2 —— 画布优先（Canvas-first）

> 依据 TapNow 画布的二次调研重做信息架构。结论一句话：
> **TapNow 的一切都发生在画布和节点上，面板是按需浮出的；我们 v1 是"后台管理系统"式的四面板常驻布局。**

## 一、调研结论（TapNow 画布交互范式）

来源：TapNow 官方文档检索摘要、腾讯新闻 Agent 教程、知乎实测长文、
复刻项目 `chapterv/Tapnow-Studio-PP` 的交互拆解（官方站点反爬，无法直接抓取截图级细节）。

1. **画布近乎满屏**：无常驻大侧栏。左侧是轻量入口（添加块/素材/历史），右键或双击画布添加块，设置面板按需出现。
2. **节点即内容**：文本 / 图片 / 视频 / 音频 / 图片编辑器节点 + 上传自有文件；模型是节点上的选项，不是独立节点。
3. **一切操作在节点上完成**：执行按钮、参数、进度、预览都在节点上；选中节点出现浮动工具条。
4. **连线语义 = 引用/上下文**：「选中图片节点，引用它生成文本节点」；点节点 + 号拖线。
5. **Agent 是核心入口**：与 Agent 多轮对话，它自动操作画布建节点、生成、写剧本；输入框可引用选中节点作上下文。
6. **画布手势**：滚轮缩放、空白拖动平移、框选批量移动、双击空白添加、双击图片 lightbox、双击节点名重命名。

## 二、v1 的问题诊断

| 问题 | 表现 |
|---|---|
| 画布被 chrome 挤压 | 左 rail(56px)+二级面板(260px)+右 Inspector(320px)+底部时间线(96px) 常驻，画布仅剩中间一块 |
| 真假混杂 | 假时间线、假「时间线/版本」导航、假协作者头像与真功能并排，可点性不可预期 |
| 操作分裂 | prompt 在节点内编辑，tone/比例/输出却要去右侧 Inspector；运行按钮存在于 3 处 |
| 缺编排入口 | 没有 TapNow 签名的底部 Composer/Agent 输入框 |

## 三、v2 目标布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：返回·Logo·项目名 | 分享/运行管线/导出/更多               │
├──┬───────────────────────────────────────────────────────────┤
│工│  ←可开合抽屉(默认收起)                                       │
│具│                                                            │
│栏│              满 屏 画 布                     ┌────────────┐ │
│  │   [↶ ↷ ?]（左上角浮动）                      │ 浮动        │ │
│  │   节点选中 → 节点上方浮动工具条               │ Inspector  │ │
│  │     (运行/复制/下载/删除)                    │ (选中才出,  │ │
│  │                                             │  可×收起)   │ │
│  │        ┌──────────────────────────┐         └────────────┘ │
│  │        │ Composer：一句话起一条管线 │                        │
│  │        └──────────────────────────┘                        │
└──┴───────────────────────────────────────────────────────────┘
```

### 设计原则
1. **画布优先**：默认只有顶栏 + 细工具栏，其余全部浮动、按需出现。
2. **节点自治**：选中节点 → 节点上方浮出工具条（运行/复制/下载/删除）；
   深度参数才去浮动 Inspector，且可随时 × 收起。
3. **诚实 UI**：删除一切假元素（时间线、版本导航、假头像、死按钮）。
   时间线等到 P2-7 有真数据再回来。
4. **Composer 即管线起点**：底部中央输入框，一句话创建预连好的
   剧本→分镜→分镜图 链（可选创建即运行）。后续 P3 升级为真 Agent
   （后端编排 API，多轮对话操作画布），输入框位置与交互不变。

## 四、本轮（v2 骨架）改动清单

- 布局：二级面板改抽屉（点当前工具开/合，默认收起）；右 Inspector 改浮动卡片
  （选中节点出现、可关闭、切换选中自动复位）；删除假时间线/假导航/假头像/死按钮
- 节点：八类节点统一接入浮动工具条 `NodeActionBar`（ReactFlow NodeToolbar）
- Composer：`createPipelineFromBrief(brief)` 建 剧本→分镜→分镜图 链并填入创意；
  「创建并运行」走 `runPipeline(ids)` 子图运行（不重跑画布上其他节点）
- 帮助：快速开始/快捷键移到画布左上角 ? 浮层（原 Inspector 空状态移除）
