## 本轮（P2-#1）交付明细

### P2-1 一键运行整条管线
- store 新增 `runPipeline()`：按 edges 做 Kahn 拓扑分层，逐层 `Promise.allSettled` 并发执行，
  保证下游节点在上游产出后才运行，从而能正确消费上游 output。
- 单节点失败不阻断整条管线（沿用 P0 的"部分失败容忍"），失败状态在节点上可见。
- 新增 `pipelineRunning` 瞬时标志（不持久化），顶栏「运行管线」按钮据此显示运行态并防重复触发。
- 环路兜底：未被拓扑覆盖的节点作为最后一层强制执行，避免漏跑。

### P2-2 工程导出 / 导入 / 新建
- store 新增 `exportProject()` / `importProject(raw)` / `resetProject()`。
- 导出为 `{ app, version, exportedAt, nodes, edges }` 的 JSON；**内存中的 base64 图片一并导出**
  （localStorage 持久化会剥离大图，导出文件是用户真正可留存/转交的工程）。
- 导入做最小校验（nodes/edges 必须为数组），格式不符给出明确报错。
- 顶栏死按钮接活：运行管线 / 分享（复制工程到剪贴板）/ 导出（下载 .json）/ 更多（导入·新建）。

### P2-3 CI 加固
- `ci.yml` 在 `npm run build` 后增加 `npm run test:tapnow`，把首页关键文案/结构校验纳入门禁。

## 验证方式
- `npm run build`（含 `tsc -b`）通过。
- `npm run test:tapnow` 通过。
- 手动：在 /studio 新建若干节点连线 → 点「运行管线」逐层跑通；导出 JSON → 新建空工程 → 导入还原。
