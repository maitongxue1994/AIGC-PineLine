### 端点与异步流程

```
POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks
Authorization: Bearer $ARK_API_KEY
Content-Type: application/json
```

请求体（首尾帧图生视频，字段名为官方原文）：

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    { "type": "text", "text": "小猫对着镜头打哈欠" },
    { "type": "image_url", "image_url": { "url": "data:image/png;base64,..." }, "role": "first_frame" },
    { "type": "image_url", "image_url": { "url": "data:image/png;base64,..." }, "role": "last_frame" }
  ],
  "resolution": "720p", "ratio": "16:9", "duration": 5,
  "generate_audio": true, "watermark": false
}
```

创建响应：`{"id": "cgt-2026..."}`。轮询：`GET .../tasks/{id}`（同鉴权），status 枚举 `queued/running/succeeded/failed/expired`，成功返回 `content.video_url` + `usage.completion_tokens`。**video_url 24h 过期、任务记录 7 天**——必须即时转存/代理取件。支持 `callback_url` 免轮询。

### 参数要点

- 首帧：单 image_url（role 可省）；首尾帧：两个 image_url，role 必填。url 支持 公网 URL / Base64（`data:image/png;base64,`，**格式名小写**）/ `asset://ID`。图片 300–6000px、<30MB、**整个请求体 ≤64MB**。
- **首帧、首尾帧、多模态参考三种场景互斥**。多模态参考（仅 2.0 系）：`reference_image` 1–9 张、`reference_video` ≤3 个（≤15s）、`reference_audio` ≤3 段。**2.0 系禁真人人脸参考图/视频**。
- `duration`：2.0 系 [4,15] 整数或 -1（智能决定），默认 5；`resolution`：480p/720p/1080p（**Fast/Mini 无 1080p**）/4k（仅 2.0 标准版）；`ratio`：`16:9/4:3/1:1/3:4/9:16/21:9/adaptive`（顶层 JSON 字段，推荐；旧 `--ratio` 文本命令兼容但弱校验）。
- `generate_audio` 默认 **true**（音画同生）；`return_last_frame` 可返回尾帧 png 做视频串接；`priority` 0–9（仅 2.0 系）。
- 2.0 系**不支持**：seed、camera_fixed、frames、离线推理、draft（draft 仅 1.5 Pro）。
- 提示词：中文 ≤500 字/英文 ≤1000 词。

### 鉴权、开通与定价

- 仅支持 API Key 鉴权：`Authorization: Bearer <ARK_API_KEY>`。申请：https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey （可按 Model ID/IP 限权）。
- **实名认证必需**（个人扫码人脸即可，无需企业）；**模型开通必需**且 2.0 系有门槛：**余额>200 元或已购资源包**。开通页：https://console.volcengine.com/ark/region:ark+cn-beijing/openManagement

- 限流（非刚性）：2.0 非 4K 个人 180 RPM/并发 3；4K 15 RPM/并发 1。
- **国际版 BytePlus**（海外免国内实名）：`POST https://ark.ap-southeast.bytepluses.com/api/v3/contents/generations/tasks`，请求体一致，model 用 `dreamina-` 前缀；Key：https://console.byteplus.com/ark/region:ark+ap-southeast-1/apiKey （邮箱注册+绑卡）。定价 2.0 480/720p $7.0/百万 token（480p·5s ≈ $0.35）。

## 二、MiniMax 海螺视频（上海稀宇）【现有 MINIMAX_API_KEY 直接可用】

### 关键结论

**与项目现有文本 API 同一 host（api.minimaxi.com）、同一套 `MINIMAX_API_KEY`**，无需新申请（前提：按量计费 Key 且有余额；视频走按量计费/视频资源包，区别于 Token Plan 订阅 Key）。

### 端点与异步流程

1. 创建：`POST https://api.minimaxi.com/v1/video_generation`（文生/图生/首尾帧/主体参考共用，靠字段区分）
   ```json
   {
     "model": "MiniMax-Hailuo-02",
     "prompt": "A little girl grow up.",
     "first_frame_image": "data:image/jpeg;base64,<...>",
     "last_frame_image": "data:image/jpeg;base64,<...>",
     "duration": 6, "resolution": "768P", "prompt_optimizer": true
   }
   ```
   → `{"task_id":"...","base_resp":{"status_code":0}}`
2. 轮询（官方建议 10s）：`GET /v1/query/video_generation?task_id=` → status `Preparing/Queueing/Processing/Success/Fail`，Success 时取 `file_id`
3. 取件：`GET /v1/files/retrieve?file_id=` → `file.download_url`（**1 小时过期**，Worker 需即时代理取件）

可选 `callback_url`：MiniMax 先 POST `{"challenge":...}` 需 **3 秒内原样回显**验证。错误码：1002 限流 / 1004 鉴权 / 1008 余额不足 / 1026 敏感内容 / 2013 参数 / 2049 无效 Key。

### 参数要点

- 模型：t2v = `MiniMax-Hailuo-2.3` / `MiniMax-Hailuo-02` / T2V-01 系；i2v 另有 `MiniMax-Hailuo-2.3-Fast`；**首尾帧 fl2v 仅 `MiniMax-Hailuo-02`**（2.3 系不能传尾帧）。
- 首/尾帧支持 Base64 Data URL 或公网 URL；JPG/PNG/WebP、<20MB、短边>300px、宽高比 2:5~5:2。
- **duration 仅 6|10**（前端 5s 需映射 6）；resolution：768P 默认；6s 可选 768P/1080P（02 的 i2v 另支持 512P）；10s 仅 768P。
- **无比例参数**——i2v/fl2v 输出比例跟随首帧图；纯 t2v 无比例控制。
- prompt ≤2000 字符，支持 `[推进][拉远]` 等 15 种运镜指令；`aigc_watermark` 默认 false（大陆版特有）。

### 定价（元/条，按条不按秒；失败不扣费）

- Hailuo-2.3：768P·6s ¥2.00、768P·10s ¥4.00、1080P·6s ¥3.50
- Hailuo-2.3-Fast（i2v）：768P·6s ¥1.35、10s ¥2.25
- **Hailuo-02：512P·6s ¥0.60、512P·10s ¥1.00**（E2E 验证首选），768P/1080P 与 2.3 同价
- 海外版 platform.minimax.io / api.minimax.io：独立账号（key 不互通），2.3 $0.28 起、02 512P $0.10。

来源：https://platform.minimaxi.com/docs/api-reference/video-generation-fl2v （及 -t2v/-i2v/-query/-download、guides/video-generation、guides/pricing-video；`.md` 后缀可 curl 拿 OpenAPI YAML）。Key 控制台：https://platform.minimaxi.com/user-center/basic-information/interface-key

## 三、通义万相 Wan（阿里云百炼 DashScope）

### 端点与异步流程

- 创建：`POST https://dashscope.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis`（t2v 与 i2v 通用；例外：老版首尾帧专用模型 wan2.2-kf2v-flash / wanx2.1-kf2v-plus 走 `.../aigc/image2video/video-synthesis`）
- **必需三头**：`Authorization: Bearer sk-xxx` + **`X-DashScope-Async: enable`**（缺失报 "does not support synchronous calls"）+ `Content-Type: application/json`
- 轮询：`GET https://dashscope.aliyuncs.com/api/v1/tasks/{task_id}`（建议 15s，查询 RPS 20）；状态 `PENDING→RUNNING→SUCCEEDED/FAILED`；成功返回 `output.video_url`（OSS 临时 URL，**与 task_id 均仅 24h 有效**）
- 首尾帧请求体（wan2.7-i2v）：`input.media` 数组 `[{type:"first_frame",url:"data:image/png;base64,..."},{type:"last_frame",url:...}]`；旧 kf2v 用 `input.first_frame_url/last_frame_url`；纯首帧 i2v 用 `input.img_url`。Base64 支持（wan2.7/2.6/2.5 ≤20MB）。

### 模型与参数

- t2v：`wan2.7-t2v`（duration 2–15 任意整数、**有 ratio 参数** 16:9/9:16/1:1/4:3/3:4）、wan2.6-t2v、wan2.5-t2v-preview（仅 5|10s）、wan2.2-t2v-plus
- i2v（首帧/首尾帧）：**`wan2.7-i2v-2026-04-25`**（media 数组、2–15s、720P/1080P，落地首选）、wan2.6-i2v(-flash)、wan2.2-i2v-plus/flash（固定 5s）、wan2.2-kf2v-flash（首尾帧最便宜、固定 5s）
- i2v/kf2v 无 ratio，比例跟随首帧图。`prompt_extend` 默认 true、`watermark` 默认 false、negative_prompt/seed 可用。

### 鉴权/定价/门槛

- `DASHSCOPE_API_KEY` 申请：https://bailian.console.aliyun.com/?tab=model#/api-key （阿里云个人实名即可，开通百炼即送**每模型 50 秒免费额度**，90 天）
- 按秒计费：wan2.7/2.6 720P ¥0.6/s、1080P ¥1/s；wan2.2-kf2v-flash 480P ¥0.10/s、720P ¥0.20/s（5s·720P 首尾帧 = ¥1/条）
- 海外地域 dashscope-intl（新加坡，同账号切换创建 Key）；Key 与地域强绑定。

来源：https://help.aliyun.com/zh/model-studio/text-to-video-api-reference 、image-to-video-general-api-reference 、image-to-video-by-first-and-last-frame-api-reference 、get-api-key

## 四、可灵 Kling（快手）

### 端点与异步流程

- Base URL：CN=`https://api-beijing.klingai.com`（**api.klingai.com 已弃用**）；海外=`https://api-singapore.klingai.com`
- 文生：`POST {base}/v1/videos/text2video` → `GET {base}/v1/videos/text2video/{task_id}`；图生（含首尾帧）：`POST {base}/v1/videos/image2video` → 同型查询。新模型（kling-3.0-turbo 等）走新接口 `POST {base}/image-to-video/kling-3.0-turbo` + `GET {base}/tasks?task_ids=`
- 状态 `submitted→processing→succeed/failed`；成功 `data.task_result.videos[0].url`（**30 天过期**）。支持 callback_url。
- 请求体示例：`{"model_name":"kling-v2-6","image":"<裸base64或URL>","image_tail":"<尾帧>","prompt":"...","duration":"5","mode":"pro","sound":"off"}`

### 鉴权与参数

- **新版 API Key（推荐，全模型）**：控制台 https://klingai.com/dev/api-key 创建后直接 `Authorization: Bearer <API Key>`；旧 AK/SK+JWT（HS256）仅老模型可用（Worker 可用 crypto.subtle 自拼，但没必要）。
- model_name：kling-v1 ~ v2-1 / v2-5-turbo / **kling-v2-6** / kling-v3；新接口 kling-3.0-turbo、kling-v3-omni、kling-video-o1。
- 首帧 `image` + 尾帧 `image_tail`：**裸 Base64（不带 data: 前缀！）**或 URL；≤10MB、≥300px、比例 1:2.5~2.5:1；首尾帧支持 v3/v3-omni/video-o1/v2-6（turbo 系仅首帧）；image_tail 与 camera_control/mask 互斥。
- duration 字符串 "3"~"15"（v2-6 3–10s）；比例 aspect_ratio 仅 t2v 有（16:9/9:16/1:1）；分辨率用 mode：std=720P / pro=1080P / 4k（仅 v3）。sound on/off（v2-6 起音画同步）。

### 定价/门槛

- CN 按秒（无声）：v2-6 std ¥0.3/s、pro ¥0.5/s（5s·1080P ≈ ¥2.5）；v3 ¥0.6–3.0/s。资源包预付费（有试用包联调）；海外版 kling.ai 独立账号 $0.14/Unit。
- 大陆手机号/快手扫码即可开通，未见强制企业认证（此点置信度中等）。

## 五、Google Veo 3.1（Gemini API）

### 端点与异步流程

- 创建：`POST https://generativelanguage.googleapis.com/v1beta/models/veo-3.1-generate-preview:predictLongRunning`，头 `x-goog-api-key: $GEMINI_API_KEY`
  ```json
  {"instances":[{"prompt":"...","image":{"inlineData":{"mimeType":"image/png","data":"<首帧base64>"}},
    "lastFrame":{"inlineData":{"mimeType":"image/png","data":"<尾帧base64>"}}}],
   "parameters":{"aspectRatio":"9:16","resolution":"720p","durationSeconds":"8"}}
  ```
  → `{"name":"models/veo-3.1-generate-preview/operations/<id>"}`
- 轮询：`GET /v1beta/{operation_name}`（10s 间隔，官方延迟 11s–6min），`done:true` 后取 `response.generateVideoResponse.generatedSamples[0].video.uri`
- 取件：GET 该 uri **须带 x-goog-api-key + 跟随 302**（不能直接给前端）；服务端视频仅保留 **2 天**。

### 参数/定价/门槛

- 模型：veo-3.1-generate-preview / -fast- / -lite-（Preview）；稳定版 veo-3.0-generate-001。
- 首帧 `image`、尾帧 `lastFrame`（仅 3.1 系，须与 image 同传）、参考图 ≤3（仅 3.1/Fast）；aspectRatio 仅 16:9|9:16（**无 1:1**）；durationSeconds "4"|"6"|"8"（**无 5/10**）；resolution 720p/1080p(仅8s)/4k(仅8s)。输出 24fps 含原生音频 + SynthID 水印。
- 定价（按输出秒）：3.1 $0.40/s、Fast $0.10/s、Lite $0.05/s（8s·720p Lite ≈ $0.40/条）。
- **现有 GEMINI_API_KEY 同 host 同头可用，但 Veo 免费层不可用**——需在 AI Studio 给项目绑定 Google Cloud 结算升 Tier 1（https://aistudio.google.com/projects ）。Gemini API 可用地区不含中国大陆/香港（ToS 层面），Worker 出口通常可通。

来源：https://ai.google.dev/gemini-api/docs/veo 、docs/video、docs/pricing#veo-3.1、docs/billing、docs/available-regions

## 七、Midjourney（视频与图片）【补充调研——**无官方 API，不建议接入**】

- 2026-07 核实官方全部 83 篇公告与帮助中心：**不存在任何官方 REST API**。唯一动作是 2025-07《Enterprise API Survey》意向问卷，至今未发布端点/时间表。
- 官方 ToS 明文禁止自动化访问与转售——市面所有「Midjourney API」（useapi/PiAPI/apiframe 等）均为违反 ToS 的灰色转售（useapi 已于 2026-06 停止 MJ 支持、PiAPI 已下线），封号风险高、无 SLA，**不可作为 PineLine 生产后端**。
- 产品现状（仅 Web/Discord）：视频 V1 模型（img2video，5s 起每次 +4s 至 21s，SD/HD 两档，`--end` 尾帧/`--loop`）；图片最新 V8.1（2026-06 起默认，`--hd` 直出 2K）。模型列表中可作展示行但标注「无官方 API」。
