# PineLine 服务交付手册（AI 生成标识 SOP）

面向：用 PineLine 给客户代工交付成片时的合规操作规范。依据《人工智能生成合成内容标识办法》（2025-09-01 生效）：AI 生成的图片/视频交付与发布需带**显式标识**（用户可感知的角标/文字）+ **隐式标识**（文件元数据/说明文档）。

## 图片

- 在 PineLine 内点「下载」已自动烧录右下角「AI 生成」角标（`src/studio/aigcMark.ts`），文件名带 `-AI生成` 后缀。直接交付即合规。

## 视频（重点：浏览器不烧标，需人工加）

PineLine 不在浏览器给视频烧角标（成本过高）。两种情况：

1. **非管理员访问码生成的视频**：已由 Seedance 供应商侧烧「AI 生成」水印（`forceWatermark`），下载即带标。
2. **管理员码自用代工的视频**（供应商未烧标）：**交付/发布前必须在剪辑软件叠加角标**：
   - 位置：画面右下角或左下角，避开主体
   - 字号：≥ 画面最短边 5%（1080p 竖屏约 ≥54px）
   - 文字：`AI 生成`（或 `AI 生成合成`）
   - 时长：**全程可见**（不是只在片头）
   - 剪映：文本 → 添加「AI 生成」 → 调到全时长；PR/DaVinci：加固定字幕轨

## 隐式标识（随附交付说明）

每次交付附一份说明文档（也是 to B 信任资产），包含：

```
作品名称：___
生成工具：PineLine（aigcpineline0419...）
使用模型：Seedance 2.0 / Gemini 3.1 / MiniMax 等
生成日期：___
说明：本作品含人工智能生成/合成内容
```

可直接用 PineLine 的「导出创作报告」（含提示词、模型、供应商 request-id、迭代时间线）作为隐式标识 + 创作过程存证（司法确权用）。

## 红线（禁止）

- ❌ 删除/篡改/隐匿 AI 标识，或为客户提供「去 AI 标识」服务——**明确违法**。
- ❌ 用火山方舟「体验中心」产物商用交付（无商用授权）；只用付费 API 通道。
- ❌ 未经授权用真人形象生成数字人。
- ❌ 生成内容模仿具体 IP 到实质性相似后商用。
- ⚠️ 科普内容涉医疗/食品安全等：保留人工审校，合同约定客户终审责任。
