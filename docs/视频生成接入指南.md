# 视频生成接入指南

> 架构：前端 runNode(video) → Worker `/api/generate/video`（创建异步任务）→ `/api/generate/video-status`（8s 轮询）→ `/api/generate/video-file`（取件代理，现查现取上游临时 URL 并流式返回）。
> Provider 实现在 `src/worker/video/`，模型清单在 `src/studio/nodeCatalog.ts` 的 `VIDEO_MODELS`。
> 端点/参数依据：`docs/模型API调研-2026-07.md`（2026-07-03 官方文档核实）。

## Seedance 2.0 接入步骤（3 步）

1. **申请 API Key**：登录[火山引擎控制台](https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey)（需实名认证，个人扫码即可）→ 火山方舟 → API Key 管理 → 创建。
2. **开通模型**：[开通管理](https://console.volcengine.com/ark/region:ark+cn-beijing/openManagement)开通 Doubao-Seedance 2.0 系列。**门槛：账户余额 > 200 元，或购买任一 2.0 资源包**（100 万 tokens 28 元起）。参考价：480p·5s 一条 ≈ ¥2.31（2.0）/ ¥1.16（Mini）。
3. **配置 Secret**（二选一）：
   - 命令行：`npx wrangler secret put ARK_API_KEY`（在 deploy/cloudflare 分支目录，或告诉我 key 由我配置）
   - Dashboard：Cloudflare → Workers → aigcpineline0419 → Settings → Variables and Secrets → 添加 `ARK_API_KEY`

配置后刷新画布，模型选择器里 Seedance 2.0 的 🔑 消失即生效。

## MiniMax 恢复可用（二选一）

2026-07-03 线上实测：创建请求已正确到达 MiniMax（参数校验通过），返回「已达到 Token Plan 用量上限」——当前 key 为订阅制 Token Plan，视频生成走**按量计费**通道。恢复方式：
- 在 [MiniMax 平台](https://platform.minimaxi.com)账户管理充值余额（视频按条计费：Hailuo-02 512P·6s ¥0.60 起），或购买视频资源包
- 或升级 Token Plan 套餐（若套餐含视频用量）

**海外主体替代路径**（免国内实名）：注册 [BytePlus](https://console.byteplus.com/ark/region:ark+ap-southeast-1/apiKey)（邮箱+绑卡），额外配 `ARK_BASE_URL=https://ark.ap-southeast.bytepluses.com`，并把 `nodeCatalog.ts` 中 Seedance 各行 `apiModel` 的 `doubao-` 前缀换成 `dreamina-`。

**Seedance 2.5**：尚未开放 API（官方口径 2026-07 内上线）。上线后仅需在 `VIDEO_MODELS` 加一行新 Model ID，Worker 零改动。

## 其他家接入步骤

- **通义万相**：[百炼控制台](https://bailian.console.aliyun.com/?tab=model#/api-key)创建 key（个人实名，送每模型 50 秒免费额度）→ 配 `DASHSCOPE_API_KEY` → 按 `docs/模型API调研-2026-07.md` §三 补全 `src/worker/video/wan.ts`（创建端点 + `X-DashScope-Async: enable` 头 + `GET /api/v1/tasks/{id}` 轮询，结构与 seedance.ts 同型）。
- **可灵**：[开放平台](https://klingai.com/dev/api-key)创建新版 API Key（Bearer 直用，勿用旧 AK/SK+JWT）→ 配 `KLING_API_KEY` → 补全 `kling.ts`（注意 base64 **不带** `data:` 前缀、域名用 api-beijing）。
- **Veo**：在 [AI Studio](https://aistudio.google.com/projects) 给现有 GEMINI_API_KEY 的项目绑定 Google Cloud 结算（Veo 无免费层）→ 补全 `veo.ts`（predictLongRunning + operations 轮询；取件需带 `x-goog-api-key`，`fetchVideo` 钩子已预留）。

## 已知参数差异（Worker 已处理/需注意）

- 时长：MiniMax 仅 6|10s（前端 5s 自动映射 6s）；Seedance 4–15s；Veo 4/6/8s
- 比例：MiniMax/Wan-i2v/Kling-i2v 无比例参数，输出跟随首帧图比例；Seedance 有顶层 `ratio`
- 尾帧：MiniMax 仅 Hailuo-02；Seedance 2.0 全系支持；Seedance 2.0 **禁真人人脸参考图**
- 临时 URL 时效：MiniMax 1h / Seedance·Wan 24h / Kling 30 天——一律经取件代理即时下载，前端拿到的是 dataURL
- 生成的视频刷新页面后不保留（persist 剥离 data: 媒体），长期留存请「保存到素材库」
