## 一、节点体系（v4 核心变化）

8 类业务节点收敛为 **3 类内容节点 + 生成预设（preset）**：

| kind | preset | 说明 |
|---|---|---|
| text | script / storyboard / ad-copy / free | 剧本 / 分镜（shots 结构化产出）/ 广告词 / 自由文本，走 MiniMax |
| image | single / shot / scene-grid / char-triview / prop-triview | 单图 / 分镜图 / 场景四宫格 / 角色三视图 / 道具三视图，走 Gemini |
| asset | —— | 上传素材，内容即本体，仅右侧输出端口 |
| video | —— | 视频节点（v4.1）：上传/播放/截帧/软剪辑为本地真实能力；生成后端接入规划中 |

- 多产出统一为 `versions: NodeVersion[]` + `activeVersion`：同时承载 三视图/四宫格、批量出图（1×/2×/4×）、高级操作的历史版本（层叠卡+批次徽章切换）。
- 原 角色/场景/道具 的**资产组织职能**由素材库（IndexedDB）承接。
- persist 升 **v4**（`migrate.ts` 无损迁移旧节点；导入旧工程 JSON 同样兼容）。

## 四、高级图像操作（对标 TapNow 图像编辑）

均以当前图为参考重新生成，**结果追加为新版本可回退**：

- **多角度**：3D 立方体拖拽 ↔ 旋转/倾斜/缩放滑杆双向联动 + 广角开关 → 相机角度提示词
- **打光**：光球拖拽（吸附六向）+ 亮度/色温滑杆 + 轮廓光 → 打光提示词
- **摄影机**：机身/镜头/焦距/光圈四列轮盘；「保存」= 节点摄影机预设（输入栏胶囊，注入后续生成）
- **蒙版重绘**：图上直绘蒙版（画笔/矩形/橡皮/粗细/撤销重做，Esc 退出模式横幅）；提交 = 原图+蒙版高亮图双参考语义指令，返回结果**按蒙版客户端 alpha 合成**——蒙版外像素逐像素等于原图（Gemini 无显式 mask 参数下的质量保底），边缘 blur 羽化

## 四·五、视频节点（v4.1，规格：docs/design/video-node-tools-README.md）

- **节点卡**（480×16:9）：播放器（悬停播放条：播放/时间/进度把手/时长/全屏）、静音/收藏、双击全屏、批次徽章；合规验证通过后外置标签带蓝勾
- **工具栏**：剪辑 / HD 增强 / 替换（上传替换）/ 移除版本 / 截帧下拉（当前帧/首帧/尾帧——真实 canvas 取帧 → 图片节点+连线）/ 更多（解析占位、Seedance 合规验证本地模拟）｜Pin｜保存素材库/下载/全屏
- **生成输入栏**：首尾帧参考（上游图片自动进位，⇄ 交换）、＋角色与焦点编辑占位、收起单行态、视频模型选择器（示例数据+锁定行解锁提示）、参数弹层（生成方式↔比例联动、5s/10s、积分即时换算 10s=202/5s=100×倍数）、提交=诚实 Toast「生成模型接入规划中」
- **剪辑模式**：离屏采样 9 帧缩略时间轴、选区把手（0.5s 吸附 / Shift 0.01s 精确）、Space 预览 / Enter 确认 / Esc 退出、智能剪辑模拟；确认派生**软剪辑**节点（播放范围 clamp，不重编码）
- **增强面板**：分辨率/帧数/放慢三行配置 + 积分区间换算（提交为占位 Toast）
- 拖入 video/* 文件（≤64MB）直接建节点；persist 对全部 `data:` 媒体剥离（视频刷新后需重新上传，可保存到素材库长期留存）

## 五、Agent（/api/agent/chat）

- 请求：`{messages(近12条), canvas快照摘要(prompt截断/不含图), selection}` → 响应 `{reply, ops[]}`
- ops：add_node(ref 临时引用) / set_prompt / set_params / rename / connect / delete_node / run
- 服务端：MiniMax 多轮 + 容错解析链（剥围栏→parse→提取{}→降级纯回复）+ 白名单校验（ops≤20）
- 前端：手动确认（操作预览卡「全部执行/放弃」）/ 自动执行；整批执行落在撤销合并窗内，⌘Z 一步撤销；run 复用拓扑执行器
