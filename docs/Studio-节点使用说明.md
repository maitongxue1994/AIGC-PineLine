# Studio 节点使用说明

> 本文档随 **画布 v4（TapNow 式工作空间）** 全面改版，内容已并入
> [`Studio-画布-v4.md`](./Studio-画布-v4.md) ——请以该文档为准。

v4 关键变化速览：

- 节点体系收敛为 **文本 / 图片 / 素材** 三类内容节点，剧本/分镜/广告词/单图/分镜图/场景四宫格/角色三视图/道具三视图 成为节点上的**生成预设**
- 提示词与参数在**选中节点下方吸附的生成输入栏**编辑（不再是节点内下拉）
- 节点上方浮动工具栏：多角度 / 重绘（蒙版）/ 打光 / 摄影机 / Pin / 保存到素材库 / 下载 / 全屏
- 左右 ⊕ 端口点击「引用该节点生成」建上下游；连线 = 上游产出自动作为下游输入（规则不变）
- 素材库（IndexedDB，刷新后仍在）承接原 角色/场景/道具 的资产组织职能
- 右下角 Agent（⌘J）：自然语言搭建/修改/运行整条管线
