# Studio 节点使用说明（v0.5 · 节点自治）

> v0.5（PRD-Studio-v3 M1）起：**右侧 Inspector 已移除**，节点的一切编辑
> （参数 / 输出 / 重命名 / 运行）都在节点上完成；状态徽章统一中文；
> 配色收敛 3 色（文本橙 / 图像紫 / 素材青）。

## 界面速览

- **底部中央 Composer**：一句话创意 →「创建管线」生成预连好的 剧本→分镜→分镜图 链；
  「创建并运行」直接按依赖跑起来（输入框内 Enter=创建，⌘/Ctrl+Enter=创建并运行）
- **选中节点 → 节点上方浮动工具条**：运行 / 复制 / 下载（有图时）/ 删除——唯一可视运行入口
- **双击节点标题** → 直接重命名（Enter 确认 / Esc 取消）
- **节点参数全部在节点上**：剧本的风格/篇幅、图像类的画幅都是节点内下拉
- **⤓ 上游输入指示条**：节点有连入线时显示（文本/图分类计数），点击选中上游节点；
  prompt/描述留空时自动使用上游输出——规则显式可见
- **左栏工具**：点击打开对应资产抽屉，再点收起（默认收起）
- **画布左上角**：撤销 / 重做 / ? 帮助（快速开始与快捷键）

## 节点类型

### Script 节点（橙色端口）
- **作用**：调用 MiniMax-M2.7 生成分镜脚本
- **输入参数**（右侧 Inspector）：
  - `Brief` — 一两句话的创意简述
  - `Tone` — 电影级 / 商业广告 / 短剧 / 纪录片
  - `Length` — 短（1 段）/ 中（3 段）/ 长（5 段）
- **输出**：脚本文本，自动写到节点预览区，可流向下游 Image 节点

### Image 节点（紫色端口）
- **作用**：调用 Gemini Nano Banana Pro（`gemini-3.1-flash-image-preview`）生成图片
- **输入参数**：
  - `Prompt` — 图像描述。**留空时自动使用上游节点的输出作为 prompt**
  - `Aspect Ratio` — 16:9 / 9:16 / 1:1 / 4:3 / 3:4
- **输出**：base64 data URL，直接显示在节点预览框内

### Asset 上传素材节点（青色端口）
- **作用**：把本地图片拖进画布生成的素材节点，不调用模型
- **用法**：直接把图片文件拖到画布空白处（一次最多 4 张，单张 ≤8MB）
- **输出**：图片本体（data URL），连到下游「图像 / 分镜图」等节点时作为参考图

## 操作

| 动作 | 方式 |
|---|---|
| 新建节点 | **双击画布空白**弹菜单；或左栏切换面板后点面板「+」；或从端口拖线到空白 |
| 上传素材 | 把图片文件直接拖进画布 |
| 连线 | 拖拽节点右侧端口 → 下一个节点左侧端口 |
| 复制节点 | 选中后 ⌘/Ctrl+D（参数复制，产出重置；素材节点连图一起复制） |
| 删除节点 | 选中后 Delete，或右侧 Inspector 底部🗑 |
| 撤销 / 重做 | ⌘/Ctrl+Z / ⌘/Ctrl+Shift+Z（仅画布结构；生成结果不回退），画布左上角也有按钮 |
| 运行单节点 | 节点底部 ▶，或 Inspector「生成」，或 ⌘/Ctrl+Enter |
| 运行整条管线 | 顶栏「运行管线」：按依赖拓扑分层，同层并发，单点失败不阻断 |
| 工程导出 / 导入 / 新建 | 顶栏「导出 ⬇」/「更多 ⋯」菜单；分享=复制工程 JSON 到剪贴板 |
| 选中节点 | 单击节点，或在左侧二级面板点对应条目；多选 / 框选见 ReactFlow 默认快捷键 |

## 二级面板（左栏）

左栏工具只切换面板，不再隐式新建节点。各面板展示**画布真实数据**：
- 剧本 / 分镜：列出对应节点与产出摘要（分镜列出镜头清单）
- 场景 / 道具 / 镜头 / 素材：汇总对应节点的产出图，点缩略图选中画布节点
- 数字演员：列出角色节点的三视图首图
- 音画：待 P2-7 接入

## 数据流约定

- 一条 edge `A → B` 把 A 的 `output` 作为 B 的默认输入
- 当 B 的 `params.prompt` 留空时，运行 B 会自动取上游 A 的 `output`
- 当 B 的 `params.prompt` 有内容时，**忽略上游**，使用本节点的 prompt

## 服务端配置

API key 通过 Cloudflare Worker 的 Secret 注入：
- `MINIMAX_API_KEY` — MiniMax 官方 Coding Plan
- `GEMINI_API_KEY` — Google AI Studio key

本地调试：复制 `.dev.vars.example` 为 `.dev.vars` 填入两个 key，运行 `npx wrangler dev`，浏览器访问 `http://localhost:8787/studio`。

## 已知限制（v0.2）

- 图片以 base64 data URL 内嵌在前端 store，单张 1~2 MB，节点过多会导致画布卡顿。后续接 R2 / KV 托管
- 没有持久化，刷新即丢
- 暂不支持视频节点
