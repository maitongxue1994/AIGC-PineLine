# Handoff: 视频节点与工具（Video Nodes & Tools）

> 来源：Claude Design 项目「工作空间UI设计」`design_handoff_video_node_tools/README.md`（2026-07-03 经浏览器提取）。
> 同目录 `video-node-tools.html` 为逐元素精确样式参考稿（见设计项目）。

## Overview
AI 节点式生成画布（node-based canvas）中 **视频节点** 的完整 UI 设计：视频节点卡片、视频浮动工具栏、截帧/更多下拉菜单、视频生成输入栏（Prompt Bar）、视频参数弹层、视频模型选择器、剪辑（Trim）模式、视频增强节点配置面板，以及 Toast 反馈。适用于 1440px+ 桌面 Web，暗色主题。

## About the Design Files
本包中的 `video-node-tools.html` 是 **HTML 设计参考稿**（design reference），展示目标外观与行为，**不是可直接复制的生产代码**。任务是在目标代码库的现有技术栈（React / Vue / 等）中，按其既有组件模式与工程规范 **重新实现** 这些设计；若尚无前端环境，请为项目选择最合适的框架后实现。文件中所有样式均为内联 style，便于逐元素查读精确值。

## Fidelity
**High-fidelity（高保真）**。颜色、字号、间距、圆角均为最终值，请像素级还原。个别插图性内容（示例视频画面、缩略帧）为渐变占位，运行时替换为真实媒体。

## Screens / Views

### 1. 视频节点卡片 Video Node Card
- **用途**：画布上的视频生成结果单元，支持播放、批次切换、收藏、静音。
- **布局**：16:9 媒体卡片（参考稿 480×270），圆角 16，描边 `rgba(255,255,255,0.16)`，阴影 `0 16px 44px rgba(0,0,0,0.55)`。
- **节点标签**（卡片上方 8px）：▶ 图标 + `Video` 文本，13px `#9A9AA2`；若已通过合规验证，后随 **15px 蓝色圆形对勾徽章**（`#2E9BFF` 底、白色 3.4 粗对勾）。
- **左上角**（12px 内边距）：两个 34×34 按钮，圆角 11，底 `rgba(10,10,12,0.65)`：静音/音量、收藏（星形）。
- **右上角**：批次切换胶囊 `2 ⌄`，padding 6/12（数字 + chevron）；悬停出现播放条与左右 24px「+」连接端口；双击全屏查看。
- **底部播放条**（悬停节点时显示）：整行 padding 14/18，背景 `linear-gradient(transparent, rgba(0,0,0,0.55))`；内容从左到右：播放/暂停图标(16px 白) · 当前时间 `9.4s`(15px/650 白) · 进度轨道(高 5px 圆角 3，底 `rgba(255,255,255,0.28)`，已播白色填充 + 15px 白色圆形拖拽把手) · 总时长 `10.0s` · 全屏图标。
- **交互**：单击选中（2px `#3F9BF5` 描边 + 外发光）；悬停出现播放条与左右 24px「+」连接端口；双击全屏查看。

### 6. 视频参数弹层
- 320px 面板，`#1E1E21`，圆角 20，padding 22，组间距 18。每组：标题 14px/600 `#D6D6DB` + 控件。
- **生成方式**：2 段分段控件（容器 `rgba(255,255,255,0.04)` 圆角 14 padding 4；选中段 `rgba(255,255,255,0.12)` 圆角 11，14px/600）：`首尾帧` / `全能参考 ⓘ`。
- **比例**（随生成方式联动）：
  - 首尾帧模式：仅整行「自适应」按钮。
  - 全能参考模式：3 格 `16:9 / 9:16 / 1:1`，每格为图形化比例框(1.6px 描边) + 文字 13px；选中格 `rgba(255,255,255,0.1)` 底、文字白。
- **清晰度**：整行按钮「自适应」（`rgba(255,255,255,0.06)`，圆角 14）。
- **生成时长**：2 段分段控件 `5s / 10s`。
- 任何参数变化即时换算积分并更新提交按钮数字（如 10s→202，5s→100）。

### 7. 视频模型选择器

## Interactions & Behavior
- 节点：hover 显示播放条与端口；选中显示工具栏与输入栏；拖拽端口连线派生节点。
- 工具栏按钮 hover `#29292C`、激活 `#2E2E31`；蓝点提醒在用户首次使用后消失。
- 参数弹层 / 模型选择器 / 截帧菜单：点击外部或再次点击触发器关闭；从触发器上方 8px 弹出，动画建议 120ms ease-out（缩放 0.98→1 + 淡入）。
- 生成方式切换 → 比例选项联动重置；参数变化 → 积分即时换算。
- 剪辑：把手拖拽有吸附；Shift 按住禁用吸附进入精确模式；智能剪辑为异步任务（进度百分比可中断）。
- 提交后：节点进入生成中占位态，提交按钮箭头替换为停止方块。

## State Management
- `selectedNodeId`、`batchIndex`（每节点当前批次）、`isPlaying / currentTime / duration / muted / starred`。
- Prompt Bar：`model, mode(首尾帧|全能参考), ratio, clarity, duration, multiplier(1|2), referenceFrames[first,last], characterRefs[], promptText, collapsed`。
- 弹层开关：`openPopover: none | params | model | frameCapture | more`。
- 剪辑：`trimStart, trimEnd, precisionMode, smartClipStatus(idle|running|done), smartClipProgress`。
- 增强：`resolution, frameRate, slowdown, creditEstimateRange`。
- 异步：生成任务队列（节点 id → status/progress），合规验证状态（per node）。

## Design Tokens
- **颜色**：画布底 `#0B0B0C`（点阵 `rgba(255,255,255,0.09)` / 22px）；面板 `#1B1B1E~#1E1E21`；输入栏 `#161618`；菜单/Toast `#232326`；控件底 `rgba(255,255,255,0.04~0.12)` 分层；文字 `#F5F5F7 / #E8E8EC / #D6D6DB / #98989F / #8A8A92 / #6E6E76`；强调蓝 `#2E9BFF`（提醒点/合规徽章/模式横幅）、`#3F9BF5`（锁/选中描边）；成功绿 `#1F8A5B`；折扣金 `#B8860B`。
- **圆角**：按钮/圆形 999；面板 20–24；卡片 14–16；菜单行 9–12；胶囊 999。
- **字体**：系统栈 `-apple-system, 'SF Pro Text', 'PingFang SC', 'Microsoft YaHei', sans-serif`；层级 16/650 面板标题、15/600 主操作、14 正文控件、13 说明、12 辅助/胶囊。
- **阴影**：浮层 `0 24px 64px rgba(0,0,0,0.65)`；工具栏 `0 16px 48px rgba(0,0,0,0.6)`；节点 `0 16px 44px rgba(0,0,0,0.55)`。
- **尺寸**：工具栏按钮 44；输入栏参考位 48；播放条控件 15–16px 图标；分隔线 1px α.12。
